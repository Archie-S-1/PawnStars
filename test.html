          Now try it yourself

          The automatic tests can't check what you see, so play one quick game against yourself using two browser tabs.

          Want to try it from another laptop or phone? Look at the black window that started the server: it shows an "Other devices on the same Wi-Fi" address. Uni Wi-Fi often blocks this, so try it at home, or skip it. The online version won't have this problem.
